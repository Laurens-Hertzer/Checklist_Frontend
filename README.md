# Checklist_Frontend

This frontend displays in the morning during my preparation routine for school a preconfigured and saved checklist with my local and live weather and trainconnection.

This repository belongs with its counterpart [Checklist_Backend](https://github.com/Laurens-Hertzer/Checklist_Backend) to the Morning Checklist System.

## Technology

This backend is written in Java (my be changed to the, at the moment, more active kotlin).

The application needs to be always online and a stable connection to the backend.
